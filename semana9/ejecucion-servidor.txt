1. Qué ocurre cuando ejecutas node server.js:
El entorno de ejecución Node.js lee el archivo JavaScript, inicializa la aplicación web utilizando el framework Express, y levanta un servidor 
local que se queda "escuchando" de forma continua de manera que está listo para recibir peticiones de red.

2. Qué mensaje aparece en la terminal:
Aparece el mensaje de confirmación programado en el código: "Servidor ejecutándose en puerto 3000".

3. Qué sucede cuando visitas la ruta /estado:
El servidor intercepta la solicitud HTTP GET realizada por el navegador web, procesa la ruta asignada y responde enviando un objeto con formato 
JSON que contiene los datos técnicos:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
